\# Rock Paper Scissors



Игра «Камень-Ножницы-Бумага» на Python.



\## Как играть



Запуск игры:



&#x20;   python game.py



Игрок вводит «камень», «ножницы» или «бумага»,

компьютер выбирает ход случайно, программа определяет

победителя раунда. Чтобы выйти из игры, введите 0.



\## Функциональность



\- Случайный выбор хода компьютера

\- Проверка корректности ввода пользователя

\- Определение победителя каждого раунда

\- Подсчёт побед игрока и компьютера (класс ScoreBoard)

\- Сохранение результатов в файл results.txt

\- Выход из игры (ввод 0)



\## Требования



\- Python 3.8 или выше

\- Внешние зависимости не требуются
